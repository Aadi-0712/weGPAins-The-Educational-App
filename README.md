# 📚 weGPAins – The Educational App

**weGPAins** is a cross-platform e-learning mobile application specifically designed for the students and staff of **Government Polytechnic, Amravati (GPA)**. Built using Flutter and Firebase, this app acts as a centralized hub for academic resources, class collaboration, and virtual learning tools — all in one platform.

---

## 📌 Features

- 🔐 **User Authentication**
  - Secure OTP-based login and registration
  - Role-based access for students and faculty

- 🏠 **Home Dashboard**
  - Scrolling intro screens and welcome interface
  - Access to virtual tools (compilers, labs, etc.)
  - Quick links to GPA website, Mahadbt, and Exam Portal
  - Integrated chatbot and e-library

- 🧑‍🏫 **ClassHub**
  - Create/join official college classes
  - Share assignments, notes, and announcements

- 📚 **Explore Section**
  - Semester-wise academic content for all branches:
    - Curriculum PDFs
    - eBooks
    - Question Papers
    - Practical & Microproject formats
    - Subject-wise video/resources links

- 🧭 **QR Location Navigator**
  - Scan QR codes to locate departments and offices on campus

- 🧩 **Side Navigation Menu**
  - Profile, Share App, Rate Us, Help Centre, Privacy Policy, Logout
  - Settings with Dark Mode and Language Switch
